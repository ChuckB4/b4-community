# B4 Indicators Community

Share, discuss and improve **NinjaTrader 8 indicators and strategies** built with [B4 Studio](https://www.b4indicators.com/studio/) and the free [B4 Developer Kit](https://www.b4indicators.com/).

**Start here → [Discussions](https://github.com/ChuckB4/b4-community/discussions)**

| Category | Use it for |
|---|---|
| **Indicators** | Post an indicator you built (source, settings, what it does, what you tested) and get feedback |
| **Strategies** | Post a strategy for review: logic, risk limits and simulation results |
| **Q&A** | Ask how to build, compile, test or fix something |
| **Show and tell** | Charts, setups, improvements to someone else's build |
| **Ideas** | Suggest features for B4 Studio and the developer kit |

## How to post a build

1. In B4 Studio, set **Visibility → Public**, add your name and choose a license.
2. Pass the public requirements on the **Share** tab, then press **Copy community post**.
3. Open a new discussion in **Indicators** or **Strategies** and paste it. The form asks for the license and what you tested.

Improving someone's build? Reply in their thread with your changes (and a share link from B4 Studio), keep their attribution, and respect their license.

## Ground rules (short version)

- **No profit claims, no signals for sale, no "guaranteed" anything.** Show what you tested and how.
- **Strategies are shared for simulation only.** Nobody here is giving trading advice.
- **Only post code you have the right to share**, under an open-source license (MIT, Apache-2.0 or MPL-2.0). No decompiled, leaked or paid third-party code.
- **Proprietary B4 code (B4 Algo, B4 confirmations, CoPilot Pro, Indicator Pro and other paid B4 tools) is never posted or requested here.**
- Be helpful and respectful. Full rules: [COMMUNITY_RULES.md](COMMUNITY_RULES.md) · [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md)
